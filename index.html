PROJECT ULTRON

Autonomous Multimodal AI Desktop Assistant & Spatial OS

Project Ultron is an autonomous, multimodal AI desktop assistant and spatial operating system engineered for macOS. It marries sub-second full-duplex conversational voice streaming (Google Gemini Live) with hardware-level operating system automation, multi-monitor visual perception, on-device biometric identification (face & voice), and an interactive 3D Spatial Visualization Engine (SVE) powered by Three.js and MediaPipe hand gestures.

Python 3 (Asyncio) Google Gemini Live API OpenCV ONNX (YuNet + SFace) macOS Quartz CoreGraphics Three.js 3D Engine MediaPipe WASM Gestures Zero-Trust Tailscale PyAudio 16/24kHz Full-Duplex

Core Architectural Pillars

1. Dual-Engine Multimodal Hub

Full-duplex 16kHz/24kHz streaming with real-time barge-in interruption handling via Gemini Live WebSocket API. Seamless offline failover to local LM Studio models with dynamic schema translation.

2. Multi-Monitor Spatial Vision

Active-monitor cursor tracking using macOS Quartz CoreGraphics. Automatically translates AI-predicted 0–1000 normalized coordinates into physical screen pixels across panoramic multi-display setups.

3. Deep macOS Hardware Automation

Direct CoreGraphics CGEvent mouse/keyboard control bypassing coordinate clamping, integrated with frontmost AX Accessibility tree queries, virtual Space inspection, and AppleScript triggers.

4. On-Device Biometric Profiling

Facial recognition using OpenCV YuNet + SFace 128-dimensional embedding vectors with cosine distance matching, combined with pure NumPy Mel-filterbank voice identification.

5. 3D Spatial Visualization Engine (SVE)

Persistent Three.js 3D workspace accepting granular delta mutations (add, update, explode, orbit, highlight) paired with local MediaPipe WASM markerless hand tracking for touchless gesture manipulation.

6. Zero-Trust Mesh & Human-in-the-Loop

Binds strictly to localhost with encrypted remote access over a private Tailscale HTTPS gateway. Critical OS shell commands hold in an asynchronous approval state machine with 45s interactive mobile approval cards.
