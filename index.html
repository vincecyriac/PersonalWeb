Autonomous Multimodal AI Desktop Assistant & Spatial Operating System for macOS

Core Architectural Pillars

1. Gemini Live Hub & Ambient Plasma Orb

Full-duplex bidirectional audio over WebSockets (gemini-3.1-flash-live-preview) with the Charon voice. The Three.js holographic plasma orb acts as the authoritative status display, syncing movement to audio playback timelines and shifting hues based on state.

2. Composable Declarative Widget Deck

Dynamic cards composed of 7 UI primitives (hero_stat, chart_svg, metric_grid, feed_list, media_view, progress_gauge, web_frame) with in-place patching via stable widget_id keys and server-side framing security checks.

3. Tiered Background Agent Delegation

Voice interaction stays instant and responsive for barge-in while multi-step heavy tasks are dispatched off-path: Gemini 3.1 Pro for OS automation/shell chains, and Gemini 3.7 Flash for constructing 3D scene graphs.

4. Spatial Visualization Engine (SVE)

Persistent 3D workspace in Three.js accepting granular delta mutations (rotate, recolor, highlight, explode) paired with local MediaPipe HandLandmarker WASM for touchless gesture manipulation (point, grab, orbit, zoom).

5. Multi-Monitor Vision & Deep OS Automation

Quartz multi-display capture with normalized coordinate mapping to physical pixels. Direct hardware-level mouse/keyboard injection via CGEventPost (kCGHIDEventTap), AX Accessibility tree queries, and AppleScript tasks.

6. On-Device Biometrics & Zero-Trust Mesh

OpenCV YuNet + SFace 128-d face recognition and pure-NumPy MFCC voice fingerprinting. Bound strictly to localhost with private Tailscale Serve HTTPS remote access and interactive one-tap shell execution approval gates.
